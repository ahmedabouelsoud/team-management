# فريق — إدارة مشروع السنتر

تطبيق عربي لإدارة مشروع برمجي لفريق واحد. القائد يدير المشاريع والمراحل والأعضاء والمهام، والعضو يرى مهامه فقط. مخطط «يومي» يفتح داخل مساحة العمل مع زر رجوع.

## التشغيل والتكلفة

- Next.js + TypeScript كتصدير ثابت.
- Cloudflare Pages Free للاستضافة، وSupabase Free للحسابات وقاعدة البيانات.
- لا يحتاج المشروع إلى مفتاح إداري في المتصفح أو خدمة بريد مدفوعة.
- شغّل `npm install` ثم `npm run dev` للتطوير المحلي. ملف `.env.local` مستثنى من Git.

## إعداد Supabase

1. نفّذ `supabase/migrations/202610210001_initial.sql` مرة واحدة.
2. أنشئ حساب القائد من Supabase Authentication، ثم غيّر دوره إلى قائد عبر SQL Editor:

   ```sql
   update public.profiles
   set role = 'leader'
   where id = '<AUTH_USER_UUID>';
   ```

3. نفّذ `supabase/migrations/202610210002_team_invites.sql` لإضافة الدعوات الآمنة.
4. نفّذ `supabase/migrations/202610210003_member_management.sql` لإتاحة إيقاف عضوية عضو مع الاحتفاظ بسجل مهامه.
5. نفّذ `supabase/migrations/202610210004_require_active_task_assignee.sql` لفرض إسناد المهام للأعضاء النشطين من قاعدة البيانات.
6. في Authentication فعّل التسجيل بالبريد وكلمة المرور. إذا أردت استخدام الدعوة من دون إعداد SMTP مدفوع، عطّل تأكيد البريد. يسمح التطبيق بإنشاء الحساب فقط برابط دعوة صالح وبالبريد المطابق؛ قاعدة البيانات ترفض الحسابات التي لا تحمل دعوة.
7. أضف متغيري `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` إلى إعدادات البناء في Cloudflare Pages.

القائد ينشئ المشروع ومراحله الأساسية تلقائيًا عند أول دخول. من تبويب الفريق يصدر رابط دعوة لمدة 14 يومًا، ويرسله للعضو على البريد المدخل. الروابط سرية وتُستخدم مرة واحدة. يمكن للقائد إيقاف عضوية عضو؛ يتوقف دخوله وتبقى مهامه وسجل عمله محفوظين. لا تستخدم `service_role` في ملفات الواجهة.

## إدارة المشاريع

القائد يضيف مشروعًا عند الحاجة، ويعدّل الاسم والوصف ورابط GitHub، وينشئ المراحل ويعيد ترتيبها أو تعديلها أو حذفها. حذف المرحلة يترك المهام المرتبطة بها محفوظة من دون مرحلة.

## النشر

التصدير الثابت يُبنى بأمر `npm run build` إلى `out/`؛ ويشغّل فحص TypeScript قبل البناء. ملف «يومي» المضمّن يحفظ خطط كل عضو محليًا في متصفحه ولا يزامنها بين الأجهزة.
